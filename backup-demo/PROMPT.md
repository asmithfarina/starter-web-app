Build a self-contained Design Tokens Playground as a single index.html file that opens by double-clicking in a browser, with inline CSS and JavaScript, no frameworks, no build step, and no network requests except an optional Google Fonts stylesheet for Inter. Style it as a clean, modern white and grey interface that looks polished on a 1440 by 900 screen. On the left, put a token panel with color pickers for primary, surface, and text, sliders for corner radius, spacing scale, and font size, and a light/dark toggle. On the right, render a live sheet of UI components driven only by CSS variables: a primary button, a secondary button, a card, a text input, a badge, a toggle, and a mini stat card. Changing any token should update every component instantly. Include a Copy CSS variables button that copies the current tokens as a :root block, and a Reset button that restores the defaults.
